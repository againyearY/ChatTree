## 🎯 1. 产品概述

### 1.1 产品定位
「枝·Branch Chat」是一款基于**对话树结构**的轻量级 AI 聊天工具。与传统线性对话工具不同，本产品将每次对话建模为树状结构，允许用户在任意历史节点创建分支，探索多种对话路径。产品采用纯前端架构，无需后端服务，**单文件即可部署**。

### 1.2 产品愿景
为创意写作、角色扮演、技术探索等场景提供一个可分支、可回溯、可存档、可深度管理的 AI 对话环境，让用户**像管理代码分支一样管理对话流**。

### 1.3 核心价值主张
- **对话分支**：任意节点可创建新分支，保留全部历史上下文
- **分支深度管理**：支持为关键分支节点添加书签和自定义标签
- **角色深度定制**：AI 与用户双方角色设定，支持自定义属性扩展
- **数据便携性**：支持完整会话数据与角色配置的一键导入/导出
- **零依赖部署**：单 HTML 文件，无需构建工具或服务器
- **数据主权**：所有数据存储在用户浏览器本地
- **多会话存档**：支持创建、切换、重命名、删除多个独立对话存档

### 1.4 技术分类
本产品属于**提示词驱动型聊天客户端**，而非 Agent 或自主体：
- ❌ 不具备自主决策能力
- ❌ 不调用外部工具/API
- ❌ 无记忆模块
- ✅ 无状态 API 调用

## 🎨 3. 使用场景

### 3.1 目标用户
- **创意写作者**：探索多条剧情线，标记关键转折点
- **角色扮演爱好者**：细致的角色设定，分支探索不同结局
- **技术探索者**：对比多个方案，标记最佳解答（但是从成本角度建议还是用cc提升效率让cc自己思考迭代，或者用免费的chatbox）

### 3.2 典型场景
```
场景一：小说剧情分支管理
1. 在关键剧情节点创建3个分支
2. 为"主角背叛"分支添加"暗黑线"标签
3. 为精彩冲突对话添加书签
4. 一周后通过书签快速找回节点
5. 通过树可视化视图评估各分支发展

场景二：角色扮演与分享
1. 设定"中世纪骑士"角色卡
2. 完成冒险对话
3. 导出角色卡分享给朋友
4. 为"和平结局"与"战争结局"分支命名
5. 导出完整会话文件备份
```

## 📱 5. UI/UX 设计

### 5.1 新增界面元素
- **树视图节点**：星标按钮(☆/★) + 双击编辑标签
- **聊天气泡**：书签金色高亮 + 标签标记块
- **聊天头部**：🌳树视图按钮 + 上下文长度指示器
- **侧边栏**：导入/导出按钮

### 5.2 交互流程
1. **添加书签**：点击节点星标 → 切换书签状态 → 金色高亮显示
2. **编辑标签**：双击节点 → 行内编辑 → 显示标签文本
3. **重新生成**：点击最后AI消息"重新生成" → 删除并重新请求
4. **可视化视图**：点击树视图按钮 → 全屏思维导图 → 点击节点切换路径
